# Challenges Log

Catatan jujur soal momen stuck selama membangun proyek ini, dan bagaimana keluar dari
situasi itu. Tujuannya dua: (1) referensi teknis untuk diri sendiri di masa depan,
(2) bahan mentah untuk Learning Log / Journey — recruiter suka melihat proses berpikir
asli, bukan cuma hasil akhir yang mulus.

Boleh ditulis sendiri, atau minta agent bantu draft berdasarkan history percakapan/commit
saat sesi debugging selesai.
